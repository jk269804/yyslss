## 📖 项目简介

**燕云十六声 · 武学助手 Pro** 是一款面向《燕云十六声》（Where Winds Meet）玩家的综合性武学数据查询与配装分析工具。项目采用纯前端技术栈，将游戏内复杂的兵器、武学、心法、奇术等数据整合为结构化体系，提供流派推荐、配装模拟、数据检索、视频素材管理等一站式功能。

---

## ✨ 功能总览

| 功能模块 | 说明 |
|----------|------|
| 🎯 **流派推荐** | 四步问答式智能推荐，从战斗定位/属性流派/兵器偏好/操作难度四维度匹配最优配装 |
| 🗡️ **兵器谱** | 8 大类兵器卡片展示，含属性流派归属、战斗定位、详细数据 |
| 📜 **武学总览** | 12 套武学体系浏览，支持按四大属性流派筛选 |
| 📖 **心法大全** | 37 本心法分类展示（金色/紫色），支持搜索与流派筛选 |
| 🌟 **奇术列表** | 战斗特技分类展示，含武学归属与属性类型 |
| ⚔️ **流派配装** | 6 套主流成型配装一站式查看，含武学搭配、心法推荐、奇术选择、输出手法 |
| 🔮 **心法模拟器** | 从 37 本心法中自由选 4 本，自动分析阵容评级与流派倾向 |
| 🎬 **视频管理** | IndexedDB 本地存储视频素材，支持上传/播放/删除/外部链接添加 |

## 🛠️ 技术栈

### 核心开发技术
- **HTML5** — 语义化标签构建页面结构
- **CSS3** — 自定义属性 + 渐变 + 动画实现暗金武侠主题
- **Vanilla JavaScript (ES6+)** — 全部交互逻辑，无框架依赖
- **IndexedDB** — 浏览器数据库存储视频素材
- **localStorage** — 配置数据持久化

### 辅助工具
- Google Fonts（Noto Serif SC + Noto Sans SC 中文字体）
- Gemini/DeepSeek LLM 辅助代码生成与优化
- Hermes Agent CLI 智能编码助手辅助开发
- Chrome DevTools 调试与性能优化

## 🚀 快速开始

### 运行环境
- 现代 Chromium 内核浏览器（Chrome 120+ / Edge 120+）
- 无需服务器，纯静态页面直接运行

### 启动方式
1. 克隆或下载项目到本地
2. 在浏览器中直接打开 `index.html`
3. 或使用本地服务器（推荐，可避免部分跨域问题）：
   ```bash
   # Python
   python -m http.server 8080
   # 或 Node.js
   npx serve .
   ```
4. 在浏览器访问 `http://localhost:8080`

### 文件结构
```
燕云武学助手/
├── index.html   ← 主程序（约 80KB，含全部 HTML/CSS/JS）
├── icon.jpg     ← 游戏图标
└── README.md    ← 本文件
```

> 所有代码整合在单一 HTML 文件中，无需额外依赖。

## 🎨 设计特色

- **暗金武侠主题**：深色背景 + 金色点缀的视觉风格，契合游戏武侠文化
- **四流派专属色彩**：鸣金（金）、裂石（橙红）、破竹（紫）、牵丝（青绿）
- **粒子动画**：首页浮动光点效果提升沉浸感
- **响应式布局**：适配桌面与移动端
- **键盘快捷键**：`Alt+1~8` 快速切换页面，`Ctrl+K` 全局搜索
- **字体选用**：Noto Serif SC 提升传统文化质感

## ⚠️ 注意事项

- 视频上传功能依赖浏览器 IndexedDB，单文件限制 **≤500MB**
- 外部视频链接（B站/YouTube 等）受浏览器安全策略限制，部分跨域视频可能无法直接播放
- 所有游戏数据为手动整理的正式服版本数据，建议跟随游戏版本更新同步维护
- 建议使用 Chromium 内核浏览器获得最佳体验
